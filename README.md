# Pylos

**The forever chat.** One conversation. Every model. Nothing forgotten silently.

Pylos is a desktop chat app (macOS, Linux) with a single text box and a single
conversation that does not end. Underneath it, an exact hash-chained archive, a
fixed-budget context compiler, a conserved loss ledger, and exact paging — so
the thread can run for a million turns, change models mid-sentence, be
exported and restored on another machine, and never let a summary quietly
become a false memory.
