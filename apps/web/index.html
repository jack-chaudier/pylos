What Pylos does

  1. #1 Remember

    Ask, don't scroll

    Every turn is kept exactly and hashed into a chain. Ask for turn 61,234, or for what Esme Whitlock said — a name planted deep in the million-turn thread you can question further down this page — and the bytes come back, not a paraphrase.

  2. #2 Bounded

    The view never grows

    The model reads a fixed budget whether the thread is ten turns or a million. Whatever the budget cannot hold is written to a ledger with an address, never dropped in silence.

  3. #3 Every model

    One thread

    Grok stops, Claude continues, a local model finishes. The thread is the agent; the model is the visitor.

What is proven, what is not

Proven

Exact recall by address. 1,000,000 turns, every planted fact, quote, number and turn reference recovered at the final checkpoint. Chain verified.

Experimental

Finding a source from different wording. On our 13-question authored set the optional local similarity route chose the intended source 6 of 13 times and a wrong one 5 of 13. A suggestion is verified against the stored bytes before it is used.

Not claimed

That any phrasing will find its source, that the model's answers are correct, or any number we have not measured.

Each card says how it reached the line: a turn number is an address, a rule you set stays in the view however old it is, a name a summary dropped keeps a way back to its turn. Two kinds of miss are told apart, and only one of them is a failure. A question about the world — one that never reaches back into this conversation — gets ⟦no turn about that · not a memory⟧: the thread has no turn on the subject, and a model would answer it from what it knows. A question that does reach back into the conversation, and reaches no turn, gets ⟦looked back, found no route to a turn · page fault⟧, and that one is receipted as a failure. Install via terminal

$ curl -fsSL https://pylos.vercel.app/install.sh | bash

  1. 01 curl … | bash — installs pylos to ~/.local/bin.
  2. 02 pylos serve — the API on 127.0.0.1:7334, loopback only.
  3. 03 Open http://127.0.0.1:7334/app/ — the same one composer, against a vault in your own home directory.

The desktop app and pylos serve share one vault format: a thread exported from either imports into the other, and the .pylos bundle verifies its hash chain on the way in. Serving it to a machine you own is supported too — pylos serve --hosted binds beyond loopback and asks for a token. Builds are unsigned for now; on macOS, right-click → Open the first time. Source, checksums and every release live on GitHub.
