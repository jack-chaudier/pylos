What Pylos does

  1. #1 Remember

    Ask, don't scroll

    Every turn is kept exactly and hashed into a chain; ask for turn 61,234 or for where Esme Whitlock lives now and the bytes come back.

  2. #2 Bounded

    The view never grows

    The model reads a fixed budget no matter how long the thread is; what the budget could not hold is written to a ledger, never dropped in silence.

  3. #3 Every model

    One thread

    Grok stops, Claude continues, a local model finishes; the thread is the agent, the model is the visitor.

Ready · seed 1 · deterministic

This is an exhibit, not the proof: the browser-safe subset of the compiler (@pylos/core/pure — no vault, no chain, no index) run in this tab over the bench's own corpus at seed 1 — the same million turns pylos bench million ingests, generated here by the same function. It computes real capsules, a real ledger and a real packet, and reports what actually happened: the closing question about the migration rule needs no page, because the rule is a certificate the frontier keeps resident; the closing question about an exact quote does, and the ledger returns the turn it is on. Keeping no vault and no index also makes its counters smaller than the bench's — 676,593 ledger entries and 1,054 MiB of archive there, less of both here; the turns are the same million. The proof is the deterministic million-turn bench artifact in bench/results. How long the run takes depends on your machine; the size of the packet does not.

Ask it something.

The kernel answering is the real one — @pylos/core/pure, running in your browser over the same thread the published bench ingests. No model is called. Every line below is archived text, or a certificate the kernel derived from archived text, and it says which route found it. The live sample in the story above replays the migration rule at turn 966 of a 2,000-turn thread; the million-turn thread here plants the same revision at turn 483,112. You can add to the thread too: start a line with remember: and it becomes turn 1,000,001.

Try

The routes are the kernel's: a turn number is an address; a standing rule is a certificate that stays resident however old it is; a name a capsule dropped has an exact locator in the loss ledger; a fact you stated outranks a fact the assistant stated; and a sentence with no name in it can only be found by searching for its words. Each card says which one fired. A question that never refers back to the conversation is answered ⟦not a memory⟧ — the thread has no turn about it, and that is not a fault. The two model answers in the migration card are recorded — they come from /bench/trap.json, the artifact the live bench wrote, with the packet hash beside them. Nothing on this page asks a model anything.

Install via terminal

$ curl -fsSL https://pylos.vercel.app/install.sh | bash

  1. 01 curl … | bash — installs pylos to ~/.local/bin.
  2. 02 pylos serve — the API on 127.0.0.1:7334, loopback only.
  3. 03 Open http://127.0.0.1:7334/app/ — the same one composer, against a vault in your own home directory.

The desktop app and pylos serve share one vault format: a thread exported from either imports into the other, and the .pylos bundle verifies its hash chain on the way in. Serving it to a machine you own is supported too — pylos serve --hosted binds beyond loopback and asks for a token. Builds are unsigned for now; on macOS, right-click → Open the first time. Source, checksums and every release live on GitHub.
