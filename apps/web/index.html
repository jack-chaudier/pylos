This is an exhibit, not the proof: the browser-safe subset of the compiler (@pylos/core/pure — no vault, no chain, no index) run in this tab from seed 0x50594C4F over a synthetic thread. It computes real capsules, a real ledger and a real packet; if the ledger does not route, it says so. The proof is the deterministic million-turn bench artifact in bench/results. How long the run takes depends on your machine; the size of the packet does not. Archive bytes are the text of the episodes plus their chain records; nothing is written to disk.

The archive is exact.

Every turn is stored verbatim in an append-only, hash-chained vault. Compaction never touches it. Export it, destroy the machine, import it on another one — the chain still verifies.

hash_i = sha256(hash_i−1 ‖ canonical(seq, ts, role, model, content_hash, meta_hash))

The view is bounded.

On every turn the compiler builds one packet within a fixed token budget: header, frontier, a fixed set of capsules covering the past (a rolling root plus the newest leaves), anything paged back, and the recent turns verbatim. It never grows with the archive.

‖K_t‖ ≤ B, for all t

Nothing is forgotten silently.

Each compaction emits a loss ledger — the names, values and quotes its text no longer contains, each with an exact locator. Ledgers are conserved upward. When a question touches one, the exact source is paged back before the model answers.

names(episodes) ⊆ names(capsule) ∪ ledger(capsule) · ledger(parent) ⊇ ⋃ ledger(child)

How it works

Four moves, repeated forever.

  1. 01 · Archive

    Every turn is appended verbatim to a hash-chained vault. The user turn commits with a pending packet, the answer commits with its derivation; a crash can never leave one without the other.

  2. 02 · Compile

    Before each reply the kernel builds one packet within a fixed budget — header, frontier, capsules, pages, recent — and records its digest.

  3. 03 · Ledger

    Each capsule records what its text no longer contains, with exact locators. Losses are conserved upward; a re-summary may add entries, never remove one.

  4. 04 · Page

    When a question names something in the ledger, the exact span comes back before the model answers. When it cannot, the model is told so.

The bound is a counting argument, not a hope: a bounded reader with b bits of resident context and t lookups of w bits can only distinguish the archive's states while b + t·w ≥ log₂(N − F − E). Pylos spends its lookups where the ledger says the artifact is missing a value, which is exactly where a compressed reader would otherwise improvise. Read the theory →
